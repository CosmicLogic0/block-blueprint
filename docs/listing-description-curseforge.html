Stop guessing. Start building.

Build Blueprint shows any build in your world as see-through ghost blocks. Place the real blocks where the ghosts are, one layer at a time, until it's done.

📂 Use your schematic files

Already have builds saved as files? Build Blueprint opens all three common kinds:

  • .litematic (Litematica)
  • .schem (WorldEdit / Sponge)
  • .nbt (structure blocks)

Put them in your WorldEdit or Litematica schematics folder, or in BlockBlueprint/builds in your user folder. They show up in Saved builds, ready to load. No other mods needed.

🔥 What it does

👻 See it before you build it
Move it, turn it, mirror it or drop it onto the ground. Press Delete to lock it in place.

🧱 Build layer by layer
One layer at a time, from the bottom up. It moves you up when a layer is done.

📋 Know what you need
A live list of every block: how many you have and how many are left. Chests near you with blocks you need glow green, and inside the chest those slots are framed in green.

🎯 Never lose your place
A box shows the next block to place. Place a block the wrong way round (like an upside-down stair) and it gets a red box telling you how it should face.

🎨 Make it yours
Click any block in the list to swap it for any other block in the game, even blocks from your other mods. Or remove it, like snow on a roof. Click the eye to hide a block's ghosts, or Shift-click to see only that block.

📸 Copy any build
See a build you like, in your world or on a server? Look at a corner, press Insert, size the box with the arrow keys and save it. Build it again anywhere.

🧩 Works with modded blocks
Builds and schematics with modded blocks load as they are. Blocks from a mod you don't have are marked, so you can swap them.

⚡ Creative mode
Auto-build places the whole build (or one layer) for you, and Undo build takes it back. On servers this needs operator rights.

💾 It remembers
Leave and come back, and your blueprint is still where you left it.

🎮 Controls

Key What it does
Page Up Open the menu
Arrow keys Move the build (Shift = 5 blocks)
Page Down Turn it
Delete Place it and start building
Home / End Layer up / down
Insert Copy a build from your world
Middle-click Hold the ghost block you're looking at

Change any key in Options → Controls.

📦 Requirements

  • Fabric: Minecraft 1.15.2, and 1.16.1 to 26.3 (needs Fabric API)
  • Forge: Minecraft 1.15.2, and 1.16.1 to 26.3
  • NeoForge: Minecraft 1.20.2 to 26.3
  • Client-side only: works in single-player and on any server.
