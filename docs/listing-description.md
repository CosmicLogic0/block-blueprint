# Build Blueprint

**See any build as see-through ghost blocks in your world, then build it block by block.**

Build Blueprint is a client-side mod for **Fabric, Forge and NeoForge**. It only runs on your computer, so it works in singleplayer **and on any server**, with nothing to install on the server.

## Copy builds from any server or world
Found a build you love on a server, a friend's world or your own old save? **Copy it**:
1. Press **Insert** while looking at one corner of the build. A box starts on that block.
2. Make the box as big as the build with the **arrow keys** (Shift = 5 blocks, Alt = shrink, Ctrl + Up/Down = top/bottom), or look at the far corner and press **Page Down** to stretch it there.
3. Press **Insert** again, give it a name, and choose whether to leave out the ground and trees.

The build is saved to your **Saved builds**, ready to place as a blueprint in any other world or server. It works anywhere you can see the blocks: no operator rights or server plugins needed.

## Features
- **Ghost preview**: every block still to place is shown as a see-through copy of the real block. Blocks in the way get a red outline.
- **Materials list**: what the build needs, what you already have, and what's still missing (whole build or the current layer).
- **Layer by layer**: build from the bottom up, one layer at a time (Home / End).
- **Move, turn and place**: arrow keys move it, Page Down turns it, Delete places (locks) it so it can't slide away.
- **Block swapping**: change a whole wood, stone or colour set at once (turn an oak boat into spruce in one click), or swap single blocks.
- **Mirror** a build, or **drop it to the ground** in one click.
- **Auto-build in Creative**: places the whole build or one layer for you (operators only on servers), with undo.
- **Next block helper**: highlights the next block to place and tells you where it is.
- **Pick from ghost**: middle-click a ghost block to grab that block from your inventory.
- **Chest finder**: chests you've opened that hold blocks you still need are outlined in green.
- **Remembers your blueprint** in every world and server, so it's still there when you come back.
- **Progress stats**: time spent and blocks per minute.
- **Schematic files**: .schem (WorldEdit / Sponge), .litematic (Litematica) and .nbt (structure blocks) show up in Saved builds, and `/buildblueprint export` saves any build as a .schem.

## Keys (all rebindable in Controls → Build Blueprint)
| Key | Does |
|---|---|
| Page Up | Menu: materials, layers, swaps, saved builds, settings |
| Arrow keys | Move the blueprint (Shift = 5 blocks, Ctrl = up/down) |
| Page Down | Turn 90° |
| Delete | Place / unlock |
| Home / End | Layer up / down |
| Insert | Copy a build |

## Free Block Blueprint app (Windows and phone)
Design builds block by block in 3D with real Minecraft textures, start from **1,400+ community templates** (shared under open licenses, each credited to its creator) or Minecraft's own buildings, then press **Send to Minecraft**. Builds you copy in-game show up in the app too. Download it from the GitHub page linked below.

## Versions
- **Fabric** 1.16.2 – 26.3 (Fabric API required)
- **Forge** 1.16.5 – 26.3
- **NeoForge** 1.20.2 – 26.3

Every file is tested before it's uploaded: the real game is started with it, joins a world and uses the mod. Files marked Beta haven't passed that test on every version yet. Found a bug? Please report it on GitHub.
